# 💰 Financial Performance Dashboard

## 📌 Overview

This project is an interactive Financial Performance Dashboard built using Power BI to monitor revenue, expenses, profit, budget, and cash flow. The dashboard provides business insights through interactive visualizations and KPIs to support financial decision-making.

## 📊 Key Performance Indicators

- 💰 Total Revenue
- 💸 Total Expenses
- 📈 Total Profit
- 🎯 Total Budget
- 💵 Net Cash Flow

---

## 📈 Dashboard Features

- Monthly Revenue Trend
- Monthly Cash Flow Trend
- Revenue vs Expenses
- Profit by Department
- Profit by Region
- Expenses by Category
- Budget vs Actual
- Interactive Slicers
- Key Insights Panel

## 📈 Business Insights

- Revenue reached **$259M** during the reporting period.
- Net Profit reached **$137M**.
- Cash Flow remained positive throughout the year.
- Budget performance stayed close to planned targets.
- IT department generated the highest profit.
- Travel was the highest expense category.
